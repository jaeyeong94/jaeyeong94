# Ted Ryu

SaaS, 개발자 도구, AI 오케스트레이션 시스템을 만들며 팀이 더 빠르게 제품을 출시할 수 있도록 돕습니다.

서울을 기반으로 일하고 있으며, 제품 엔지니어링, 워크플로우 설계, 실용적인 AI 통합을 중심으로 작업합니다. 복잡한 구조보다 유지보수 가능한 단순한 구조와 명확한 전달 방식을 선호합니다.

## 어떤 일을 하나요

- 명확한 사용자 흐름과 운영 편의성을 갖춘 SaaS 제품 개발
- 반복 작업을 줄이는 개발자 도구와 내부 플랫폼 구축
- 실제 팀 프로세스에 맞는 AI 오케스트레이션 시스템과 자동화 워크플로우 설계 및 구현

## 일하는 방식

- 기술보다 먼저 실제 병목을 파악합니다
- 첫 릴리스 이후에도 유지할 수 있는 단순한 구조를 지향합니다
- 제품팀과 엔지니어링팀이 빠르게 판단할 수 있도록 작은 단위로 나눠서 전달합니다

## 주요 작업

- [jaeyeong94.github.io](https://github.com/jaeyeong94/jaeyeong94.github.io)  
  경력, 작업물, 글을 간결하게 정리한 개인 웹사이트 및 이력서 사이트입니다.
- [blog](https://github.com/jaeyeong94/blog)  
  엔지니어링, 제품 관점, 일상적인 개발 워크플로우에 대한 글과 메모를 정리하는 공간입니다.
- [rootstone-dashboard](https://github.com/jaeyeong94/rootstone-dashboard)  
  사용성, 유지보수성, 정보 전달력을 중심으로 만든 대시보드 성격의 제품 작업입니다.
